# Learn Claude

A curated directory of the best places to learn Anthropic's Claude.

What makes it different from every other link list: **every resource says who should
skip it**, shows the date we last checked it, and carries an honest label for how
thoroughly we checked. A link with no judgment is just a list, and lists are what made
this hard in the first place.

Not affiliated with Anthropic.

**Live: https://mojtaba-alehosseini.github.io/learn-claude/**

## Run it

Open `index.html`. That is the whole procedure — no server, no build, no install.

Pushing to `master` deploys. `.github/workflows/deploy.yml` runs `build.sh` on the
runner, so `data/*.js` stays out of git and the live site can never disagree with
`data/items.json`.

The data loads through `<script>` tags rather than `fetch()`, specifically so the site
works opened straight from a folder. Browsers block `fetch()` on `file://`, and a
directory nobody can open locally is not much of a directory.

## Change the data

`data/items.json` is the source of truth. After editing it:

```
./build.sh
```

That regenerates ids, publisher names, the learning paths, the search index, and the
JavaScript mirrors of the JSON. Every step is safe to re-run.

## Layout

```
index.html  browse.html  paths.html  resource.html  how-we-check.html
assets/css/tokens.css     every colour, size, radius and font
assets/css/site.css       the classes, all built from those tokens
assets/js/ui.js           shared: the card, badges, chips, dates
assets/js/*.js            one per page
assets/icons/roles/       40 drawings — 10 roles x 4 levels
assets/icons/formats/     7 drawings — one per format
data/items.json           the catalogue
data/paths.json           generated by scripts/build-paths.py
scripts/                  the pipeline
docs/specs/               what we decided and why
docs/design/              the design brief and the UX copy
```

## The rules that matter

**Never invent a resource.** Every entry needs a real URL that has been opened, and a
date it was checked. If it is not verified, it does not ship.

**`skip_if` may never be empty.** `scripts/validate-report.py` rejects entries without
it. It is the product.

**Only a person may write `tier: reviewed`.** No automated stage can claim a human read
something. The validator enforces this.

**Ids come from the URL, never from list position.** An earlier version numbered items
by their row, and when the catalogue grew every learning path silently re-pointed at
different resources while still printing confident explanations. See
`scripts/stable-ids.py`.

**Search has no API call.** A static page cannot hold an API key, so ranking is keyword
matching with IDF weighting over the hidden fields written offline. Run
`python3 scripts/test-search.py` — it uses the identical algorithm to the browser, so a
ranking regression shows up there first.
