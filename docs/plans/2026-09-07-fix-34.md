# FIX-34 Implementation Plan

> **For agentic workers:** Execute task-by-task with `anthropic-skills:executing-plans`
> (inline, one session — the round record, the commit hygiene and the D4 checkpoint are all
> held in one head). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land the four FIX-34 rulings, close the class of "a script that cannot say no",
and give the catalogue a `needs` field with its first 40 rows recorded from the pages.

**Architecture:** Static site; `data/items.json` is the source of truth, `build.sh` runs
every gate through `gate()` and `scripts/test-gates.py` plants a fault per gate. Every
change here is either a rule in a validator (with a planted fault), a rendering in
`assets/js/*.js`, or data recorded into `items.json`. Nothing new is invented: the `needs`
chip reuses `.chip`, the `why` lift reuses the `.sp-cta` pattern, the ladder and skip
figures are new keys on `measure.py`'s dict.

**Tech Stack:** Python 3 (stdlib only — the deploy runner installs nothing), Node for the
two JS tests, plain HTML/CSS/JS. Windows Git-Bash has `python` not `python3`; a shim at
`tmp/bin/python3` is prepended to `PATH` before `build.sh`.

## Global Constraints

- One commit does one job. Commit messages via `git commit -F tmp/msg-*.txt`; the
  commit-msg hook rejects any count in a message.
- Never `git add -A`. Name the paths. `Nowcasting_Econ-Report-v16.pdf` and
  `Nowcasting_Econ-Report_Appendix.pdf` are Morteza's and are never staged.
- Never put a regex or a backslash through a heredoc — write the script to `tmp/` and run
  the file.
- Numbers a reader reads are generated or measured, never typed. `check-typed-numbers.py`
  scans `docs/THE-PROJECT.md`, `README.md`, `docs/START-HERE.md`; `docs/attack/` is
  exempt (dated by construction).
- A check whose failure cannot be seen is not a check: every new gate gets a planted fault
  in `scripts/test-gates.py` and the harness is run before push.
- A failing gate is fixed or reverted before push. Never explained.
- Round ends pushed; deploy runs on push. Verify live with a `cache:'reload'` fetch — the
  preview browser runs stale JS (memory: `preview-serves-stale-js`).
- Copy in ASD-STE100, plain English. Chip labels change in `docs/design/ux-copy.md` first.
- Not ours: STATUS.md "Needs a person", THE-PROJECT part 10, the human test, the paste
  into Teams.
- The D4 data pass stops if page and card disagree on more than three of the 40 rows.

```python
    in_deck = set(re.findall(r"^\| `([a-z-]+)(?::<name>)?` \|", deck, re.M))
    return keys, prefixes, in_deck


def check_needs(items, bad, vocab):
    keys, prefixes, in_deck = vocab
    for n, item in enumerate(items):
        needs = item.get("needs")
        if needs in (None, []):
            continue
        if not isinstance(needs, list):
            bad(n, item, "needs must be a list"); continue
        for v in needs:
            base, _, slug = str(v).partition(":")
            known = (base in keys and not slug) or (base in prefixes and slug and SLUG.match(slug))
            if not known:
                bad(n, item, "needs value %r is outside the vocabulary in ui.js LC.NEEDS "
                             "(a prefixed value wants a lowercase slug)" % v)
            elif base not in in_deck:
                bad(n, item, "needs value %r has no row in docs/design/ux-copy.md — add "
                             "the reason before the value" % v)
```
