Tiempos Fine Medium — measured, rejected, deleted

Medium is not shown here any more because the file is gone. It was one of the 36 faces no stylesheet referenced, and those were deleted on 2026-08-24 rather than left sitting in a public repository. It measured 151% of Georgia's total ink in Chrome at 20px — half again as much — which is why it read as bold rather than as slightly heavy. The numbers are in body-weight-measurement.md. To see it again, check the file out of a commit before that date.
