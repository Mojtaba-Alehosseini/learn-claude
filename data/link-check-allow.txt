# Hosts the weekly link check must treat as `blocked` no matter what they return.
#
# One host per line. Anything after a `#` is the reason, and the reason is the point.
#
# ## What this is for, and what it is NOT for
#
# scripts/check-links.py already reads 401, 403, 429 and 451 as "blocked us" rather than
# "gone", so a host that answers with a clean 403 needs no entry here. This file is for
# the harder case: a host that is alive but answers automation with silence — a timeout,
# a reset connection, an empty body — which the classifier would otherwise call `wobbly`
# every week for ever.
#
# Add a host only after opening the URL in a real browser and seeing it work. An entry
# here permanently suppresses a real signal for that host, so each one is a small
# promise that somebody looked.

education.gov.au   # Times out from a GitHub Actions runner, every time. Verified alive in
                   # a browser 2026-08-22 and again by the resource's own notes. See below.

# ## The same check, two places, two answers
#
# Run over all 352 URLs twice on 2026-08-27:
#
#     from a home connection      333 ok · 0 gone · 19 blocked · 0 wobbly
#     from a GitHub Actions runner 314 ok · 0 gone · 37 blocked · 1 wobbly
#
# Same script, same minute, nearly double the blocking. Datacentre IP ranges are refused
# by hosts that will happily serve a laptop. This is the single most important number in
# this file: a checker developed against a home connection and shipped to CI would have
# filed 37 dead links on its first run, and the catalogue has none.
#
# The 19 seen locally were ten hosts, all clean 403s, all handled automatically:
#
#     datacamp.com                 4      medium.com                   4
#     udemy.com                    4      uxdesign.cc                  1
#     designsystemscollective.com  1      students.unimelb.edu.au      1
#     monash.edu                   1      ethicscentral.org            1
#     spj.org                      1      niemanlab.org                1
#
# uxdesign.cc and designsystemscollective.com are Medium publications, so that is really
# one host wearing three names.
#
# ## The one entry above, and why it took two runs to earn
#
# The Australian Framework for Generative AI in Schools carries this in its own `notes`:
# "Blocks automated requests, so link checkers report it dead."
#
# From a home connection it answered 200, and that was written up as a prediction that
# had not survived contact. It had. From the runner — which is the only place this check
# actually runs — it timed out, exactly as the note said, and became the single `wobbly`
# of the run. The note was right and the first test was in the wrong place.
#
# Worth remembering the next time a host looks fine: the question is never "does it
# answer me", it is "does it answer the runner".
